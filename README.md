# Canter — The Open Trail

A small, responsive endless runner built with HTML, CSS, and JavaScript. Ride across the countryside, jump over fences and hay bales, and see how far you can go.

## Play

Open `index.html` in a modern browser. No installation or build step is needed.

| Action | Control |
| --- | --- |
| Start or ride again | Click **Start riding** / **Ride again**, or press Space, ↑, or W |
| Jump | Press Space, ↑, or W; click/tap the game canvas; or tap **JUMP** |
| Pause or resume | Press P or Escape, or use the pause button |
| Sound | Use the speaker button |
| Fullscreen | Use the fullscreen button; press Escape or use the button to exit |

Jump over obstacles to keep your run going. The game speeds up as you travel farther. Your best distance is saved in your browser's local storage.

## Files

- `index.html` — page structure and game controls
- `styles.css` — responsive layout and interface styling
- `script.js` — canvas art, animation, physics, audio, and game state

The game uses no JavaScript dependencies. Google Fonts are optional; system font fallbacks are provided.
